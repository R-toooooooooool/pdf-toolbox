PDF Toolbox extension

For Chrome and Edge. Send the PDF you’re viewing into the toolbox with one click: merge and split, add text, highlight, watermark, snapshot, extract text. Files are processed on your computer and never uploaded.

⬇ Download the extension Version 2026.10.29.1728 (2026-10-29) · 5.0 MB

What’s new

2026-10-29

  • Merge: add Word, Excel and CSV files directly — they’re turned into PDF pages first (still never uploaded)
  • Images: WebP, GIF and BMP now work too

2026-10-29

  • English version: click “EN” at the top right to switch; Help is in English too
  • Add text: 🖍 highlighter, box, circle, line and arrow, with color, width and solid or dashed lines
  • A notice at the top lists what’s new when there’s a new version — you choose whether to update (reminders can be turned off in Help)

What it adds to the web version

  • While viewing a PDF in the browser, click the toolbar icon to send it straight into the toolbox — no download needed
  • Right-click a PDF link → “Open with PDF Toolbox”; add several one by one into the same toolbox and merge them
  • Everything is built in, so it works offline (recognizing scans downloads data the first time)
  • When there’s a new version, a notice lists what’s new and you decide whether to update (“Not this version” skips it; you can also turn reminders off in Help)
  • Click “EN” at the top right of the toolbox to switch to English

Install

  1. Click “Download the extension” above, right-click the zip → “Extract All”, and keep the folder somewhere it won’t be deleted (e.g. C:\PDF-Toolbox-Extension). Don’t move or delete it afterwards.
  2. Go to chrome://extensions (Edge: edge://extensions) and turn on “Developer mode” (top right in Chrome; bottom of the left menu in Edge).
  3. Click “Load unpacked” and choose the folder from step 1 (you should see manifest.json inside).
  4. Click the puzzle-piece icon next to the address bar and pin PDF Toolbox so the blue icon stays on the toolbar.

A “Disable developer mode extensions” notice appears when the browser starts?

Just close it or click “Keep” — don’t disable it.

Updating

  1. When the toolbox shows “A new version…”, click “Download new version” (or “Download the extension” on this page).
  2. Right-click the zip → “Extract All” → “Browse” and choose the folder where the extension is installed → Extract; choose “Replace the files in the destination” when asked.
  3. Back in the toolbox, click “Done — reload” (or click the circular arrow on PDF Toolbox in chrome://extensions).

Your settings (naming rules, fix list) are kept.

Privacy

  • PDFs are processed entirely on your computer and never uploaded to any server.
  • The only network use: downloading recognition data the first time you recognize a scan, feedback you choose to send, and a version check each time it opens (it only reads the version number and sends nothing).
  • The first time you read a PDF from a site, you’ll be asked to click “Allow”; only the PDFs you send are read.
Don’t want to install anything? Use the web version of PDF Toolbox — it does the same.

PDF 工具箱 擴充功能

給 Chrome、Edge 用。正在看的 PDF 按一下就送進工具箱：合併分割、加字、螢光筆、浮水印、擷取畫面、取文字。檔案全在你的電腦處理，不會上傳。

⬇ 下載擴充功能 版本 2026.10.29.1728（2026-10-29）・5.0 MB

這一版新功能

2026-10-29

  • 合併分頁可以直接放 Word、Excel、CSV，會先轉成 PDF 頁面再合併（一樣不上傳）
  • 圖片多支援 WebP、GIF、BMP

2026-10-29

  • 新增英文版：右上角按「EN」切換，說明頁也有英文
  • 加字分頁新增 🖍 螢光筆、方框、圓圈、直線、箭頭，可以選顏色、粗細、實線或虛線
  • 有新版時會在上方提醒並列出新功能，可以選擇要不要更新（說明頁也能關掉提醒）

比網頁版多了什麼

  • 正在瀏覽器裡看 PDF 時，按工具列的圖示，這份 PDF 直接送進工具箱，不用先下載
  • 網頁上的 PDF 連結按右鍵 →「用 PDF 工具箱開啟」；好幾份可以一份一份加進同一個工具箱再合併
  • 需要的程式都裝在裡面，沒網路也能用（掃描檔認字第一次要上網下載辨識資料）
  • 有新版時，工具上方會提醒並列出新功能，要不要更新由你決定（按「這版先不要」就不更新；說明頁也能關掉提醒）
  • 工具右上角按「EN」可以切換成英文

第一次安裝

  1. 按上面的「下載擴充功能」，在下載的壓縮檔按右鍵 →「全部解壓縮」，把資料夾放在不會被刪掉的地方（例：C:\PDF工具箱擴充功能）。之後不要搬動或刪掉這個資料夾。
  2. 網址列輸入 chrome://extensions（Edge 是 edge://extensions），打開「開發人員模式」（Chrome 在右上角；Edge 在左邊選單下方）。
  3. 按「載入未封裝項目」（Edge 叫「載入解壓縮」），選第 1 步的資料夾（裡面要看得到 manifest.json）。
  4. 按網址列右邊的拼圖圖示，把 PDF 工具箱旁邊的圖釘按下去，藍色圖示就會一直在工具列上。

開瀏覽器時跳出「停用開發人員模式擴充功能」？

按「關閉」或「保留」就好，不要按停用。

更新到新版

  1. 工具上方出現「有新版」時按「下載新版」（或在這頁按「下載擴充功能」）。
  2. 在壓縮檔按右鍵 →「全部解壓縮」→ 按「瀏覽」選你當初放擴充功能的資料夾 → 解壓縮；問要不要取代時，選「取代目的地中的檔案」。
  3. 回到工具箱按「換好了，重新載入」（或到 chrome://extensions 在 PDF 工具箱上按圓形箭頭）。

你的設定（命名規則、常錯字對照表）會保留。

檔案安全

  • PDF 全部在你自己的電腦上處理，不會上傳到任何伺服器。
  • 會連上網路的只有：掃描檔第一次認字時下載辨識資料、你在「回報區」主動送出的意見、每次打開時看一下有沒有新版（只讀版本號，不送出任何資料）。
  • 第一次從某個網站讀 PDF，會請你按「允許讀取」，只會讀你送進來的那份 PDF。
不想安裝？直接用 網頁版 PDF 工具箱，功能一樣。
